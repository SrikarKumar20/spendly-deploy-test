# Spendly — a mini expense tracker (HTML + CSS + TypeScript)

A small starter project. Boilerplate (HTML, CSS, `tsconfig`, build script) is done for you. Your job: complete the TypeScript in `src/app.ts` so the app works, then **deploy it** and submit.

> 👉 Full task list + marks: see **[TODO.md](./TODO.md)**.

## What you build
An Expense Tracker where a user can add an expense (title, amount, category), see all expenses listed, and see the **total** plus a **per-category breakdown**. Invalid input is rejected.

## Getting started

```bash
# 1. Install the TypeScript compiler
npm install

# 2. Compile src/app.ts -> dist/app.js (strict mode, must be 0 errors)
npm run build
#    or keep it running while you work:
npm run watch

# 3. Open the app
#    Just open index.html in your browser (double-click it),
#    or serve the folder, e.g.:
npx serve .
```

`index.html` loads the **compiled** `dist/app.js` — always run the build after editing `src/app.ts`.

Publish the app to **one** of these and paste the live link below. Because this is plain HTML + compiled JS, deployment is simple — just make sure `dist/app.js` is built and committed.
